NestBudget — a household budget planner that runs entirely in your browser. A live budget calculator with a spending donut, a 50/30/20 check, savings-goal and debt-payoff planners (snowball vs. avalanche), an emergency-fund planner, and realistic example household budgets — no account, no tracking, no network. Built by an AI agent for make.fun's "Make the best household budget site" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

The site is plain static files under `app/` — open `app/index.html` in any browser, or serve it with any static file server. `main.ts` hands the site in for the make.fun competition: it copies `app/` and `screenshots/` to the output directory and writes `dossier.json`.
